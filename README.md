# BilleFlash

Billetera personal rápida: anotas tus gastos en segundos, ves tu límite del día, tus cuentas en Bs y soles, lo que te deben y lo que tienes que pagar. Cierras tu día cada noche y tu racha sube.

- PWA offline, sin servidores ni analítica.
- Datos cifrados solo en el teléfono (patrón y huella).
- Respaldo en `.txt`.

```bash
npm install
npm run dev
npm run check
```
